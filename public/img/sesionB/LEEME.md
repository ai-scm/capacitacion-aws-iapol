# Capturas de la Sesión B (IAMAPS — Analítica Geoespacial)

Coloca aquí los PNG del paso a paso del portal IAPOL. Mientras no existan, la
plataforma muestra un marcador con la descripción y la ruta destino.

Anonimiza las capturas: tapa datos sensibles, nombres propios y ubicaciones
precisas si aplica.

## Archivos esperados (nombre exacto → qué debe mostrar)

| Archivo | Qué capturar |
|---|---|
| `acceso-menu.png` | Menú izquierdo de IAPOL con "Analítica Geoespacial". |
| `catalogo-buscar.png` | Catálogo con el buscador por palabra clave en uso. |
| `catalogo-filtro-unidad.png` | Filtro por unidad aplicado en el catálogo. |
| `historico-carga.png` | Ventana de carga al abrir un mapa histórico. |
| `historico-filtro-delito.png` | Mapa histórico con filtro por tipo de delito. |
| `nuevo-mapa-boton.png` | Botón "Nuevo mapa" en el apartado derecho. |
| `cargar-datos.png` | Pantalla de cargue con "Browse your files"/arrastre. |
| `add-data.png` | Botón "Add Data" para sumar fuentes. |
| `add-layer.png` | Panel de capas con "Add Layer". |
| `capa-config.png` | Configuración de capa abierta (selector "Basic"). |
| `capa-estilo.png` | Panel de estilo: Fill Color, Outline, Radius, Label. |
| `capa-agrupacion.png` | Capa de hexágonos o mapa de calor. |
| `filtros-pestana.png` | Pestaña de filtros con datasets cargados. |
| `filtro-delito.png` | Filtro por campo "delito" con un valor elegido. |
| `filtro-tiempo.png` | Filtro de fecha con etiqueta "time" + línea de tiempo. |
| `rango-tiempo.png` | Rango seleccionado en la línea de tiempo. |
| `tooltip.png` | Tooltip con los campos de un dato sobre el mapa. |
| `exportar-imagen.png` | Opción de exportar el mapa como imagen. |
| `guardar-mapa.png` | Formulario de guardar (nombre, descripción, grupo). |
| `anticipacion-mapa.png` | Mapa "Anticipación a Fenómenos" con sus capas. |
| `buscar-unidad.png` | Botón "Buscar unidad" + jerarquía de unidades. |

Formato recomendado: PNG, ancho ~1200–1600 px, relación apaisada.
